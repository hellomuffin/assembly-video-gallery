# Assembly video journal

Public video showcase. Open index.html or serve this directory with any static HTTP server.

Only selected simulation videos and stills are published here; no research dataset payloads or credentials are included.

Furniture-derived media: IKEA3DAssemblyDataset, CC BY-NC-SA 4.0, https://github.com/IKEA/IKEA3DAssemblyDataset . Body creator: Assistive Gym, MIT, https://github.com/Healthcare-Robotics/assistive-gym . Egocentric footage re-renders a saved successful trajectory from a virtual camera; it is not a head-tracked full-body demonstration. Complete assembly and separate operation demonstrations are labeled on the page.
