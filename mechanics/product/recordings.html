The recording parts are hosted in this project’s GitHub release. The videos remain on the gallery page.

Save every part, the checksum manifest, and reassembly script in one folder. Run python reassemble_recordings.py there. The script verifies all checksums and creates recordings.zip, which you can extract normally.

The script uses only the Python standard library and does not download or execute any simulation code.
